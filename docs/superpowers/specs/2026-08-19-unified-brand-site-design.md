# אתר תדמית מאוחד לחשבונאוטיקה — Design Spec

## Background

היום ה-repo מכיל כמה דפי נחיתה נפרדים ולא מתואמים (`index.html`, `tutors.html`, `guides/index.html`, `שיווק הולד/index.html`) — כולם בסגנון dark/neon/glow, כל אחד עם funnel המרה משלו וקוד Apps Script כפול. המטרה: לאחד הכל לאתר תדמית מלא אחד, עם זהות ויזואלית חדשה, שמתפקד כצינור (pipeline) שמוביל הורים/מורים/מוסדות מהבנת המוצר ועד כניסה בפועל למערכת בכתובת `aritmetica.nt-school.app`.

הדומיין הסופי של האתר התדמיתי: `heshbonautica.nt-school.app`.

## Goals

- אתר תדמית רב-עמודי אמיתי (לא אוסף landing pages), שמסביר את חשבונאוטיקה, החזון והמודלים למורים ולהורים.
- שני מסלולי המרה מקבילים (מורים / הורים) שמתכנסים לאותה מערכת חיה, פלוס נתיב פנייה למוסדות (ליד בלבד, ללא כניסה עצמאית).
- זהות עיצובית חדשה: "חללית הנדסית" — גריד כבידה (gravity-well grid), גלאסמורפיזם, מערכת סולארית אמביינטית ברקע שנעה/זזה בין העמודים כדי ליצור תחושת מסע רציף.
- אלבום/גלריית מדיה משודרגת (גיפים זזים, מעברים אוטומטיים, נוחה במובייל) שממחישה את המוצר בפועל.

## Non-Goals

- לא בונים את מערכת ה-Aritmetica עצמה (הדשבורד/המשחקים) — רק את שכבת התדמית/השיווק שמובילה אליה.
- לא קובעים מחירון סופי בשלב זה — ממתינים לקובץ מהמשתמש, בינתיים placeholder ברור.
- לא מחליטים סופית על אסטרטגיית איסוף הנתונים (Apps Script קיים מול משהו חדש) — המשתמש ביקש לשקול אחרי שיראה את העיצוב; יש להשאיר את זה כנקודת החלטה מפורשת בתוכנית היישום, לא הנחה שקטה.

## Site Map & Page Flow

```
index.html (בית / חזון)
   │  hero: "למידה במסלול אחר לגמרי" + מערכת סולארית ברקע
   │  הסבר על חשבונאוטיקה
   │  גלריית מדיה (גיפים/תמונות, אוטו-רוטציה, לייטבוקס מותאם מובייל)
   │  3 כרטיסיות בתחתית: מורים | הורים | מוסדות (אנימציית hover בין מורים/הורים)
   │
   ├─→ teacher.html (מסלול מורים)
   │       הסבר על ההצעה למורים + מחיר
   │       CTA: "השאירו פרטים ונחזור אליכם"  → guide-teacher.html (אחרי שליחת טופס)
   │       CTA: "כניסה למערכת" → guide-teacher.html (ישר, בלי טופס חובה)
   │
   ├─→ parent.html (מסלול הורים)
   │       הסבר על ההצעה להורים + מחיר
   │       CTA: "השאירו פרטים ונחזור אליכם" → guide-parent.html
   │       CTA: "כניסה למערכת" → guide-parent.html
   │
   └─→ (כרטיס מוסדות — לא נתיב עמוד נפרד, פותח טופס/מודל פנייה ישירה בעמוד הבית, ליד בלבד)

guide-teacher.html / guide-parent.html
   מדריך קצר ומפושט (מבוסס על התוכן הקיים ב-index.html/tutors.html, מקוצר)
   כפתור סופי → aritmetica.nt-school.app (עם /teacher לפי הצורך)
```

כל עמוד הוא קובץ HTML נפרד (multi-page אמיתי, לא אנקורים בתוך עמוד יחיד). המערכת הסולארית האמביינטית ברקע משנה מיקום/זווית/קנה מידה בין עמוד לעמוד כדי לתת תחושת רצף מסע ולא איפוס.

## Visual System

**זהות**: "חללית הנדסית" — טכני ומהונדס, לא neon/glow ילדותי. הכיוון שאושר משלב הבחירה הוויזואלית (ראה `.superpowers/brainstorm/*/content/visual-style-v5.html` לדוגמת ה-canvas החיה):

- **גריד כבידה**: רשת פרספקטיבה (floor grid לכיוון אופק) שנכפפת/warping סביב "מסה" זוהרת — מוטיב חוזר לרקעי הירו והפרדות סקשנים.
- **מערכת סולארית אמביינטית**: כוכב מרכזי זוהר + "כוכבי לכת" זכוכית (glass planets) שנעים במסלולים אליפטיים, עם פרלקס עדין בגלילה. בהשראת ה-reference HTML ששלח המשתמש (NovaSys) — אך *לא* כבסיס לכל האתר, רק לעמוד הבית/חזון (ו"מוטמע" כבר בתוך אריתמטיקה עצמה, מחוץ לסקופ).
- **גלאסמורפיזם**: כרטיסים/פאנלים `backdrop-filter: blur` עם border עדין ו-inset highlight, בשימוש בכל העמודים לתוכן מונגש מעל הרקעים האמביינטיים.
- **טיפוגרפיה**: Space Grotesk לכותרות (אנגלית/מספרים), Heebo לגוף הטקסט העברי. RTL מלא.
- **פלטה**: בסיס חלל כהה עמוק (`#030508`–`#0A0E16`), מבטאי כחול-שמיים (`#8AB4FF`) וסגול-אינדיגו (`#9D8BFF`), עם אפשרות מבטא טורקיז/כתום-אש למצבי סטטוס/CTA לפי עמוד.
- **תנועה**: כל אנימציה איטית ועדינה (opacity/scale נמוכים, מהירויות נמוכות) — לא מסיחה מהתוכן, לא "מתחרה" בטקסט.

## Content Sourcing

- הסברי "מה זו חשבונאוטיקה", היתרונות למורים/הורים, וצעדי המדריך — מבוססים על התוכן הקיים ב-`index.html` וב-`tutors.html`, אך **מפושטים ומקוצרים**, לא מועתקים כלשון.
- גלריית המדיה (`albumData`) עוברת כמעט as-is מהקוד הקיים (רשימת gif/jpeg + כיתובים), רק בעטיפת carousel/lightbox חדשה.
- מחירון: placeholder ברור ("מחירון בקרוב" / מבנה placeholder לכרטיסי מסלול) עד קבלת הקובץ מהמשתמש.

## Media Gallery Behavior

- ממוקם בעמוד הבית, לפני הכרטיסיות בתחתית.
- קרוסלה עם מעבר אוטומטי בין פריטים (רואים אותה תזוזה יחסית לאלבום הקיים, אך עכשיו עם auto-advance, לא רק לחיצה ידנית).
- גיפים ממשיכים לזוז לבד (הם GIF-ים אנימטיביים ממילא).
- פתיחה ללייטבוקס במובייל: תמונה/גיף חייבים להיכנס למסך שלם בגובה סביר (לא לדרוש גלילה אופקית/אנכית כדי לראות את כל הפריט) — כלומר `object-fit: contain` בתוך container שמתאים לגובה viewport במובייל, לא פריסה שנועדה קודם-כל לדסקטופ.
- ניווט קליק שמאל/ימין + מקלדת (כפי שקיים כבר) נשמר.

## Data Collection

טרם הוכרע. שתי אופציות פתוחות שיש להציג כהחלטה מפורשת בתחילת שלב היישום (לא להניח בשקט):

1. להמשיך עם ה-Apps Script הקיים (`script.gs`, ה-URL הקבוע ב-`index.html`/`tutors.html`), רק עם payload/מיפוי שדות מותאם למבנה החדש.
2. לשנות אסטרטגיה (למשל איסוף נפרד לכל מסלול, שינוי בשדות הטופס).

המשתמש ביקש לבחור אחרי שיראה את העיצוב הבנוי בפועל.

## Open Items

- מחירון סופי (ממתין לקובץ מהמשתמש).
- החלטת איסוף נתונים (ראה למעלה).
- תוכן מדויק לכרטיס "מוסדות" (הטקסט/שדות בטופס הפנייה) — כרגע ידוע רק שזו פנייה ישירה, בלי כניסה עצמאית למערכת.
